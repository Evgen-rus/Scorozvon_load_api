## 📋 Описание проекта

Этот проект содержит скрипты для работы с API сервиса **Скорозвон** (автоматизированные звонки). Все скрипты написаны на Python и используют библиотеку `requests` для HTTP-запросов.

## 📁 Файлы проекта

### `list_projects.py`
**Назначение:** Получает и выводит список всех доступных проектов (кампаний звонков) из аккаунта Скорозвона.

**Что делает:**
- Авторизуется в API с помощью OAuth токена
- Запрашивает проекты постранично (по 200 проектов на страницу)
- Выводит ID и названия проектов в формате: `ID — Название`

### `upload_contacts.py`
**Назначение:** Загружает список телефонных номеров как лиды (контакты) в указанный проект Скорозвона.

**Что делает:**
- Создаёт новые лиды в проекте
- Привязывает каждый номер телефона к проекту
- **Не проверяет дубликаты** — если номер уже есть, создаст ещё один лид

### `upload_contacts_dedup.py`
**Назначение:** Загружает телефонные номера с проверкой на дубликаты (deduplication).

**Что делает:**
- Перед созданием каждого лида проверяет, существует ли уже такой номер в проекте
- Пропускает дубликаты, выводя сообщение о пропуске
- В конце показывает статистику: сколько создано, сколько пропущено
- **Заполняет поля лидов:**
  - **Название лида:** номер телефона без плюса (например: "79991234567")
  - **Описание:** "Аквилон_новые номера"
  - **Теги:** ["столица_перехват"]

### `3_upload_from_xlsx.py`
**Назначение:** Загружает контакты из Excel файла (.xlsx) в указанный проект Скорозвона.

**Что делает:**
- Открывает диалог выбора Excel файла
- Читает телефонные номера и комментарии из первых двух столбцов файла
- Создаёт лиды без проверки на дубликаты
- Показывает статистику загрузки и обработанные номера
- **Заполняет поля лидов:**
  - **Название лида:** "ФИО не указано" (или можно изменить в коде)
  - **Телефон:** из первого столбца файла
  - **Комментарий:** из второго столбца файла (застройщик/комментарий)
  - **Теги:** ["столица_перехват"] (можно изменить в коде)

### `get_lead_by_id.py`
**Назначение:** Получает и выводит подробную информацию о лиде по его ID.

**Что делает:**
- Запрашивает ID лида у пользователя
- Получает полную информацию о лиде из API
- Выводит все доступные поля: имя, телефоны, комментарий, теги, даты создания и обновления

### `get_project_info.py`
**Назначение:** Получает информацию о проекте звонков и показывает сводку по его лидам.

**Что делает:**
- Получает детальную информацию о проекте по его ID
- Показывает настройки проекта: название, статус, сценарий, расписание звонков
- Выводит количество лидов в проекте
- Показывает примеры первых лидов (имя, телефон, комментарий, теги)

## 🔧 Требования для запуска

### Системные требования:
- Python 3.7+
- Установленные зависимости из `requirements.txt`:
  ```
  requests==2.32.5
  python-dotenv==1.0.1
  openpyxl==3.1.5
  ```

### Установка зависимостей:
```bash
pip install -r requirements.txt
```

## ⚙️ Настройка переменных окружения (.env)

Файл `.env` содержит чувствительные данные для доступа к API Скорозвона:

```env
SKOROZVON_LOGIN=ваш_email@domain.ru
SKOROZVON_API_KEY=ваш_api_ключ
SKOROZVON_APP_ID=ваш_app_id
SKOROZVON_APP_KEY=ваш_app_secret
```

### Где получить эти данные:

**Зарегистрируйтесь или войди** в системе Скорозвон (https://skorozvon.ru)
**Перейдите в настройки API:**
https://app.skorozvon.ru/#/settings/integration/api
**Скопируйте**
Логин:
API-ключ:
ID приложения:
Ключ приложения:

### Инструкция для клиента

1. Войдите в свой аккаунт в Скорозвоне под пользователем, у которого есть права загружать лиды:
   https://app.skorozvon.ru/

2. Перейдите в настройки API:
  https://app.skorozvon.ru/#/settings/integration/api

3. В открывшемся окне скопируйте и мне пришлите данные для интеграции:
   Логин
   API-ключ
   ID приложения
   Ключ приложения

4. Напишите мне название проекта, в который нужно загружать лиды.

5. Еще можете скинуть форму, через которую вы загружаете лиды, чтобы я прописал все поля корректно.


## 🚀 Запуск скриптов

Все скрипты запускаются из командной строки:

```bash
# Список проектов
python list_projects.py

# Загрузка контактов без дедупликации
python upload_contacts.py

# Загрузка контактов с дедупликацией
python upload_contacts_dedup.py

# Загрузка контактов из Excel файла
python upload_from_xlsx.py

# Получение информации о лиде по ID
python get_lead_by_id.py

# Получение информации о проекте
python get_project_info.py
```

### Изменение параметров:
- В `upload_contacts*.py` и `upload_contacts_dedup.py` измените `project_id` на нужный ID проекта
- В `upload_contacts*.py` и `upload_contacts_dedup.py` замените `test_phones` на свой список номеров
- В `upload_from_xlsx.py` можно изменить `CALL_PROJECT_ID`, `DEFAULT_TAGS`, `LEAD_DEFAULT_NAME`
- В `get_project_info.py` измените `project_id` на нужный ID проекта

### Формат Excel файла для upload_from_xlsx.py:
Файл должен содержать данные начиная со второй строки (первая - заголовки):
- **Столбец A:** Телефонные номера (в любом формате, с плюсом или без)
- **Столбец B:** Комментарии/застройщики (опционально)

**Пример файла:**
```
Телефон       | Застройщик
79991234567   | ЖК Солнечный
+79991234568  | ЖК Лесной
```

### Примеры номеров телефонов:
```python
phones = [
    "+79991234567",
    "79991234568",  # без плюса тоже работает
    "+7(999)123-45-69"  # формат не важен, берутся только цифры
]
```

## ⚠️ Замечания по безопасности:
- Скрипты имеют **низкий риск** — только чтение проектов или создание контактов
- Все запросы логируются в консоль для отладки
- При ошибках авторизации скрипты завершаются с кодом 1
- **Замечание:** `upload_from_xlsx.py` использует графический интерфейс для выбора файла (tkinter). При запуске на сервере без GUI может потребоваться headless режим или X11 forwarding.
